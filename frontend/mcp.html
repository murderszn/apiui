01 // OVERVIEW MODEL CONTEXT PROTOCOL

What Is MCP?

The Model Context Protocol (MCP) standardizes how AI models and coding agents inspect schemas and query external datasets without custom glue code.

02 // CLIENT CONFIGURATION CLAUDE DESKTOP · CURSOR · ANTIGRAVITY

How To Connect

Active MCP Server: http://localhost:8000

For Claude Desktop, Cursor & Antigravity

Ready-to-copy mcpServers JSON config pointing to your active backend:


                        
Uses Streamable HTTP transport at http://localhost:8000/mcp. Live config JSON is also served at GET /mcp/client-config.

                    


                    

                        
Direct MCP & HTTP Endpoints

                        
Your active self-hosted backend exposes spec-compliant MCP transports and dataset REST endpoints:

                        

                            

                                

                                    POST http://localhost:8000/mcp
                                    Streamable HTTP
                                

                                
JSON-RPC 2.0 endpoint (initialize, tools/list, tools/call, resources/list)

                            

                            

                                

                                    GET http://localhost:8000/mcp/sse
                                    SSE Transport
                                

                                
Server-Sent Events stream with POST /mcp/messages

                            

                            

                                

                                    GET http://localhost:8000/mcp/resources
                                    List Files
                                

                                
Retrieve a list of all uploaded files and dataset metadata

                            

                            

                                

                                    GET http://localhost:8000/mcp/client-config
                                    Client Config
                                

                                
Machine-readable mcpServers JSON for desktop & IDE clients
