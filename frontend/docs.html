01 // REST API QUERYING /API/<JOB_ID>/DATA · /SCHEMA · /CODE

REST API QUERYING

Every uploaded dataset is automatically exposed at /api/<job_id>/data with column filtering, full-text substring search, sorting, and pagination—plus live schema and generated code routes.

Dataset Endpoints

REST
  • GET /api/<job_id>/data — Query rows with filtering, search, sorting, and pagination.
  • GET /api/<job_id>/schema — Inspect inferred column names, data types, nullability, and row counts.
  • GET /api/<job_id>/code — Retrieve generated FastAPI source code and route metadata.
curl -s "http://localhost:8000/api/<job_id>/schema" | jq .
curl -s "http://localhost:8000/api/<job_id>/code"

Query Parameters

FILTER & SORT
?<column>=value

Exact column filter on any field in your dataset.

_search=term

Case-insensitive substring match across all columns.

_sort & _order

Sort by column name with asc or desc.

_limit & _offset

Paginate results (aliases limit / offset supported).

curl -s "http://localhost:8000/api/<job_id>/data?status=active&_search=pro&_sort=price&_order=desc&_limit=20&_offset=0"
02 // MCP PROTOCOL REFERENCE STREAMABLE HTTP · SSE · 4 TOOLS

MODEL CONTEXT PROTOCOL

Connect Claude Desktop, Cursor, Windsurf, or any MCP-compatible AI client directly to your datasets over Streamable HTTP (POST /mcp) or SSE (GET /mcp/sse).

Transports & Client Config

HTTP + SSE
  • POST /mcp — Spec-compliant Streamable HTTP JSON-RPC 2.0 endpoint.
  • GET /mcp/sse — Server-Sent Events stream for SSE MCP clients.
{ "mcpServers": { "apiui": { "url": "http://localhost:8000/mcp" } } }

4 Built-In MCP Tools

JSON-RPC 2.0
list_datasets

Lists available APIs, job IDs, row counts, and endpoints.

get_dataset_schema

Returns columns, types, and sample metadata for a job.

query_dataset

Filters, searches, sorts, and paginates dataset rows.

summarize_dataset

Computes summary statistics and distributions for a dataset.

curl -X POST "http://localhost:8000/mcp" \ -H "Content-Type: application/json" \ -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
03 // SELF-HOSTED & HOME MINI-PC SETUP PORT 8000 BACKEND · PORT 8080 FRONTEND · LAN

SELF-HOSTED & MINI-PC SETUP

Run the complete apiUI stack on your Mac, Linux box, or home mini-PC with zero external cloud dependencies. config.js automatically resolves your backend on localhost or LAN.

Quick Start Local Stack

PORTS 8000 / 8080

Launch both the Python API/MCP backend (port 8000) and the Node frontend server (port 8080) in one command:

chmod +x start-local.sh ./start-local.sh

Frontend UI: http://localhost:8080 • Backend & MCP: http://localhost:8000

Connecting Over LAN

HOME MINI-PC

Bind your mini-PC's LAN IP so laptops, phones, or local AI agents on your home network can reach your datasets:

HOST=0.0.0.0 PORT=8000 API_GATEWAY_URL=http://192.168.1.50:8000 ./start-local.sh # Or override backend URL in any browser tab: # http://192.168.1.50:8080/app.html?backend=http://192.168.1.50:8000
