Overview

apiui is a powerful platform that transforms your CSV, Excel, or other data files into fully functional REST APIs. Instead of spending hours writing backend code, you can upload your data and instantly get a production-ready API endpoint.

How It Works

  1. Upload Your Data: Simply drag and drop your CSV, Excel (.xlsx/.xls), or other supported file formats
  2. Automatic Analysis: Our system analyzes your data structure and infers column types, relationships, and optimal API design
  3. API Generation: We automatically generate FastAPI server code with proper data models, validation, and endpoints
  4. Instant Deployment: Your API is deployed and ready to use within seconds
  5. Query Your Data: Use standard REST API calls to query, filter, and manipulate your data

Key Features

  • ✅ Automatic data type detection
  • ✅ RESTful API endpoints
  • ✅ Query parameters support
  • ✅ Pagination built-in
  • ✅ JSON response format
  • ✅ CORS enabled
  • ✅ Input validation
  • ✅ Error handling

Quick Start

1. Prepare Your Data

Create a CSV file with your data. Make sure the first row contains column headers: 

name,email,department,salary
John Doe,john@example.com,Engineering,75000
Jane Smith,jane@example.com,Marketing,65000
Bob Johnson,bob@example.com,Engineering,80000

2. Upload Your File

Drag and drop your file onto the upload area or click to browse and select your file.

Supported formats: CSV, Excel (.xlsx/.xls), Parquet, TXT

3. Wait for Processing

The system will analyze your data, generate the API code, and deploy it automatically. This usually takes 30-60 seconds.

What happens during processing:

  • • Data structure analysis and column type detection
  • • Automatic FastAPI code generation
  • • REST endpoint creation with proper routing
  • • Data validation and error handling setup
  • • API deployment and endpoint activation

4. Test Your API

Once your API is ready, you can test it directly from the app using the "Test API" button:

Test API Button Features:

  • • Inline Testing: Shows pass/fail status without opening new windows
  • • Real-time Feedback: Immediate results with visual indicators
  • • Automatic Reset: Status clears after 3 seconds
  • • Error Details: Clear messages for any connection issues

5. View API Documentation

Click the "API Docs" button to see comprehensive documentation for your API:

Documentation Features:

  • • Available Endpoints: Complete list of all API routes
  • • Interactive Code Examples: Copy-ready examples in multiple languages
  • • Copy Buttons: One-click copying for all code snippets
  • • Advanced Usage: Filtering, sorting, and pagination examples

6. Generate Server Files (Optional)

If you want to run your API locally or deploy it elsewhere, click "Run Generated API" to create the actual server files:

Generated Files Include:

  • • main.py: Complete FastAPI server code
  • • requirements.txt: All Python dependencies
  • • data.csv: Your original data file
  • • api_code.txt: Documentation-ready code with examples
# To run your API locally:
cd /path/to/generated/api
python main.py

# API will be available at: https://apiui-backend-24bi767viq-uc.a.run.app

API Endpoints

GET

/data

Retrieve all records from your dataset

Query Parameters:

  • limit - Number of records to return (default: 100)
  • offset - Number of records to skip (default: 0)
  • [column_name] - Filter by column value

Example:

GET /data?limit=10&department=Engineering
GET

/data/{id}

Retrieve a specific record by ID

Example:

GET /data/123
GET

/data/schema

Get the data schema and column information

Example:

GET /data/schema

Code Examples

JavaScript (Fetch API)

// Get all data
fetch('https://your-api-endpoint.com/data')
  .then(response => response.json())
  .then(data => console.log(data));

// Get data with filtering
fetch('https://your-api-endpoint.com/data?department=Engineering&limit=5')
  .then(response => response.json())
  .then(data => console.log(data));

// Get specific record
fetch('https://your-api-endpoint.com/data/123')
  .then(response => response.json())
  .then(data => console.log(data));

Python (Requests)

import requests

# Get all data
response = requests.get('https://your-api-endpoint.com/data')
data = response.json()
print(data)

# Get data with filtering
params = {'department': 'Engineering', 'limit': 5}
response = requests.get('https://your-api-endpoint.com/data', params=params)
data = response.json()
print(data)

# Get specific record
response = requests.get('https://your-api-endpoint.com/data/123')
data = response.json()
print(data)

cURL

# Get all data
curl "https://your-api-endpoint.com/data"

# Get data with pagination
curl "https://your-api-endpoint.com/data?limit=10&offset=20"

# Get data with filtering
curl "https://your-api-endpoint.com/data?department=Engineering&salary[gte]=50000"

# Get specific record
curl "https://your-api-endpoint.com/data/123"

# Get schema information
curl "https://your-api-endpoint.com/data/schema"

System Requirements

File Requirements

  • ✅ Maximum file size: 100MB
  • ✅ First row must contain headers
  • ✅ UTF-8 encoding recommended
  • ✅ Consistent data types per column
  • ✅ No empty header names

Data Quality

  • ✅ Clean, consistent data
  • ✅ Proper date formats
  • ✅ Valid numeric values
  • ✅ No special characters in headers
  • ✅ Unique identifier column (recommended)

Best Practices

  • • Use descriptive column names (e.g., "first_name" instead of "fn")
  • • Include an ID column for record identification
  • • Ensure consistent date formats across your data
  • • Remove any unnecessary columns before uploading
  • • Test your API with small datasets first

Troubleshooting

Common Issues & Solutions

API Test Button Shows "Fail"

The inline test indicates connection problems

  • • Server Status: Check if the API server is running
  • • Network Issues: Verify your internet connection
  • • API State: Ensure the API wasn't stopped or deleted
  • • Page Refresh: Try refreshing the page to reload API status

File Upload Rejected

Your file upload is being rejected

  • • Format Check: Ensure file is CSV, Excel (.xlsx/.xls), Parquet, or TXT
  • • File Integrity: Verify the file isn't corrupted or empty
  • • Size Limits: Check if file exceeds size restrictions
  • • Special Characters: Remove special characters from filename

Processing Takes Too Long

API generation seems stuck or slow

  • • Large Files: Bigger files naturally take longer to process
  • • Complex Data: Intricate data structures need more analysis time
  • • Connection Speed: Check your internet connection stability
  • • Retry Process: Refresh and try uploading again

Documentation Issues

Problems with API documentation or copy buttons

  • • Modal Loading: Wait for the documentation modal to fully load
  • • Copy Function: Ensure you're using a modern web browser
  • • Code Examples: All examples are dynamically generated for your API
  • • Advanced Section: Click the arrow to expand advanced examples

Getting Help

If you continue to experience issues:

  • • Browser Console: Check for detailed error messages in browser developer tools
  • • Page Refresh: Simple page refresh often resolves temporary issues
  • • Support: Contact our support team through available channels
  • • Bug Reports: Help us improve by reporting any persistent issues
