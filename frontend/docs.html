Overview

apiUI is an AI-powered platform by AURABLOX that transforms your data files into fully functional REST APIs. Upload CSV, Excel, JSON, Parquet, or text files and instantly get production-ready API endpoints with automatic data analysis, type inference, and FastAPI code generation.

How It Works

  1. Upload Your Data: Drag and drop CSV, Excel, JSON, Parquet, or TXT files
  2. Instant Preview: Automatic data analysis and type detection with immediate preview
  3. AI Generation: OpenAI GPT-4 creates production-ready FastAPI code with Pydantic models
  4. Live APIs: Working REST endpoints with filtering, sorting, and pagination
  5. Deploy Anywhere: Download complete server packages for local or cloud deployment

Key Features

  • ✅ Multi-format file support (CSV, Excel, JSON, Parquet, TXT)
  • ✅ AI-powered FastAPI code generation with OpenAI GPT-4
  • ✅ Automatic data type inference and schema analysis
  • ✅ Instant mock APIs while AI generation runs
  • ✅ RESTful API endpoints with full CRUD operations
  • ✅ Advanced filtering, sorting, and search capabilities
  • ✅ Pagination and real-time status monitoring
  • ✅ Pydantic model validation and error handling
  • ✅ Complete server deployment packages
  • ✅ Multiple authentication methods and API management

Quick Start

1. Prepare Your Data

Create a CSV file with column headers in the first row: 

name,email,department,salary
John Doe,john@example.com,Engineering,75000
Jane Smith,jane@example.com,Marketing,65000

2. Upload & Preview

Drag and drop your CSV, Excel, JSON, Parquet, or TXT file. Get instant data preview with automatic type detection and validation.

3. Generate API

Click "Generate API" to start AI-powered FastAPI code generation. Get immediate mock endpoints while the full API builds in the background.

4. Use Your API

Test your API with the built-in testing tools, view interactive documentation, and download deployment-ready server files.

System Requirements

File Requirements

  • ✅ Maximum file size: 100MB
  • ✅ First row must contain headers
  • ✅ UTF-8 encoding recommended
  • ✅ Consistent data types per column
  • ✅ No empty header names

Data Quality

  • ✅ Clean, consistent data
  • ✅ Proper date formats
  • ✅ Valid numeric values
  • ✅ No special characters in headers
  • ✅ Unique identifier column (recommended)

Best Practices

  • • Use descriptive column names (e.g., "first_name" instead of "fn")
  • • Include an ID column for record identification
  • • Ensure consistent date formats across your data
  • • Remove any unnecessary columns before uploading
  • • Test your API with small datasets first

API Endpoints

Mock API Endpoints (Immediate)

Available immediately after upload for instant testing. These endpoints serve your actual data while AI code generation completes in the background.

GET

/mock-api/{job_id}/data

Retrieve all records from your dataset with pagination and filtering

Query Parameters:

  • limit - Number of records to return (default: 10, max: 1000)
  • offset - Number of records to skip (default: 0)
  • [column_name] - Filter by column value (exact match)

Example:

GET /mock-api/abc123/data?limit=5&department=Engineering
GET

/mock-api/{job_id}/schema

Get the data schema and column information

Response includes:

  • • Column names and inferred types
  • • Nullability information
  • • Unique value counts
  • • Sample data preview

Example:

GET /mock-api/abc123/schema
GET

/mock-api/{job_id}/code

Get the AI-generated code files (when available)

Returns:

  • • main.py - Complete FastAPI application
  • • requirements.txt - Python dependencies
  • • dockerfile - Container configuration

Example:

GET /mock-api/abc123/code

Generated API Endpoints (After AI Processing)

Production-ready FastAPI endpoints generated by AI. These become available after the background code generation completes.

Note: Generated APIs use custom endpoints based on your data structure. Use the "API Docs" button in the app to see the exact endpoints for your specific API.

Code Examples

JavaScript (Fetch API)

// Get all data
fetch('https://your-api-endpoint.com/data')
  .then(response => response.json())
  .then(data => console.log(data));

// Get data with filtering
fetch('https://your-api-endpoint.com/data?department=Engineering&limit=5')
  .then(response => response.json())
  .then(data => console.log(data));

// Get specific record
fetch('https://your-api-endpoint.com/data/123')
  .then(response => response.json())
  .then(data => console.log(data));

Python (Requests)

import requests

# Get all data
response = requests.get('https://your-api-endpoint.com/data')
data = response.json()
print(data)

# Get data with filtering
params = {'department': 'Engineering', 'limit': 5}
response = requests.get('https://your-api-endpoint.com/data', params=params)
data = response.json()
print(data)

# Get specific record
response = requests.get('https://your-api-endpoint.com/data/123')
data = response.json()
print(data)

cURL Commands

# Get all data
curl -X GET "https://your-api-endpoint.com/data"

# Get data with pagination
curl -X GET "https://your-api-endpoint.com/data?limit=10&offset=0"

# Filter data
curl -X GET "https://your-api-endpoint.com/data?department=Engineering"

# Get schema
curl -X GET "https://your-api-endpoint.com/schema"

# Get specific record
curl -X GET "https://your-api-endpoint.com/data/123"

Troubleshooting

Common Issues & Solutions

API Test Button Shows "Fail"

The inline test indicates connection problems

  • • Server Status: Check if the API server is running
  • • Network Issues: Verify your internet connection
  • • API State: Ensure the API wasn't stopped or deleted
  • • Page Refresh: Try refreshing the page to reload API status

File Upload Rejected

Your file upload is being rejected

  • • Format Check: Ensure file is CSV, Excel (.xlsx/.xls), Parquet, or TXT
  • • File Integrity: Verify the file isn't corrupted or empty
  • • Size Limits: Check if file exceeds size restrictions
  • • Special Characters: Remove special characters from filename

Processing Takes Too Long

API generation seems stuck or slow

  • • Large Files: Bigger files naturally take longer to process
  • • Complex Data: Intricate data structures need more analysis time
  • • Connection Speed: Check your internet connection stability
  • • Retry Process: Refresh and try uploading again

Documentation Issues

Problems with API documentation or copy buttons

  • • Modal Loading: Wait for the documentation modal to fully load
  • • Copy Function: Ensure you're using a modern web browser
  • • Code Examples: All examples are dynamically generated for your API
  • • Advanced Section: Click the arrow to expand advanced examples

Getting Help

If you continue to experience issues:

  • • Browser Console: Check for detailed error messages in browser developer tools
  • • Page Refresh: Simple page refresh often resolves temporary issues
  • • Support: Contact our support team through available channels
  • • Bug Reports: Help us improve by reporting any persistent issues
