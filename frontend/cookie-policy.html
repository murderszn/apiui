COOKIE POLICY

Learn how apiUI uses cookies and local browser storage to keep your Studio sessions fast, predictable, and completely under your control.

01 // What Are Cookies 02 // Cookie Categories 03 // Browser Controls 04 // Updates & Contact
LOCAL-FIRST STORAGE

Self-hosted apiUI deployments store Studio session flags and backend gateway URLs locally in your browser via localStorage with zero ad-network trackers.

01 // WHAT ARE COOKIES? DEFINITIONS · STORAGE MECHANICS

BROWSER TEXT & SESSION TOKENS

Cookies are small text files placed on your computer or mobile device when you visit a website. Alongside localStorage, they keep your workspace state intact across page reloads.

01.A // FORMAT

Small Text Files

Stored on your device by your browser when visiting web applications.

01.B // CONTINUITY

Improve Experience

Remember Studio preferences, gateway URL overrides, and active sessions.

01.C // SAFETY

Non-Executable Data

Plain key-value strings that cannot execute code or carry malware.

01.D // CONTROL

User Controllable

You can inspect, restrict, or clear stored cookies at any time.

02 // HOW WE USE COOKIES ESSENTIAL · ANALYTICS · FUNCTIONAL · MARKETING

We categorize browser cookies and local storage keys into four operational buckets based on their role in the platform:

CAT 01 // REQUIRED SESSION / 30D

Essential Cookies

Required for core platform operation, including Studio session state, CSRF protection, and backend endpoint routing.

Duration: Session or up to 30 days • Scope: Core Security
CAT 02 // TELEMETRY UP TO 2Y

Analytics Cookies

Help us understand aggregate visitor traffic and feature adoption on hosted deployments through anonymized metrics.

Duration: Up to 2 years • Scope: Aggregated Metrics
CAT 03 // WORKSPACE UP TO 1Y

Functional Cookies

Remember custom backend gateway overrides (?backend=), active MCP client tabs, and workspace preferences.

Duration: Up to 1 year • Scope: Preferences
CAT 04 // CAMPAIGNS UP TO 1Y

Marketing Cookies

Used only on public promotional campaigns when enabled to measure campaign attribution and relevance.

Duration: Up to 1 year • Scope: Optional Attribution
